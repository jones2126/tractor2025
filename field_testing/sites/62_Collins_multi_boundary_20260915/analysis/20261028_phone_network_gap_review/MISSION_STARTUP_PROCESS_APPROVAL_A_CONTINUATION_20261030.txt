5. START AUXILIARY EVIDENCE COLLECTION
======================================================================

Open a second PuTTY terminal if possible. Re-establish the variable there:

    export TRACTOR_STATIONARY_RETEST_DIR=/home/al/field_logs/20261030_stationary_direct_retest
    sudo -v

Record ZeroTier peer state every two seconds even though it is not the control
path. Stop this sampler after the trial with the saved PID:

    while true; do
      date --iso-8601=seconds
      sudo zerotier-cli peers
      sleep 2
    done > "$TRACTOR_STATIONARY_RETEST_DIR/zerotier-peers-continuous.log" 2>&1 &
    export TRACTOR_ZT_SAMPLER_PID=$!

Record bounded Pi/network counters:

    while true; do
      date --iso-8601=seconds
      uptime
      vcgencmd measure_temp 2>/dev/null || true
      ip -s link show eth0
      sleep 2
    done > "$TRACTOR_STATIONARY_RETEST_DIR/pi-network-health.log" 2>&1 &
    export TRACTOR_HEALTH_SAMPLER_PID=$!

Optional encrypted-port packet metadata, only if tcpdump is already installed:

    if command -v tcpdump >/dev/null 2>&1; then
      sudo timeout 660 tcpdump -i any -nn -s 128 -C 10 -W 10 \
        -w "$TRACTOR_STATIONARY_RETEST_DIR/direct-8767-%02d.pcap" \
        'tcp port 8767' > "$TRACTOR_STATIONARY_RETEST_DIR/tcpdump-console.txt" 2>&1 &
      export TRACTOR_PCAP_PID=$!
    fi

Do not install packages or change router/network configuration on test day.

6. RUN ONE CLEAN TEN-MINUTE DIRECT DRY-RUN WITH NTFY ENABLED
======================================================================

In the primary PuTTY terminal:

    export TRACTOR_STATIONARY_RETEST_DIR=/home/al/field_logs/20261030_stationary_direct_retest
    cd /home/al/tractor2025
    python3 -u tractor_rpi/testing/webrtc/wifi_primary_control_20261022.py \
      --host 192.168.8.20 \
      --port 8767 \
      --dry-run \
      --simulate-bridge \
      --authority-policy tractorfield-mission \
      --control-subnet 192.168.8.0/24 \
      --tls-cert /home/al/.config/tractor-wifi-control/tls/server.crt \
      --tls-key /home/al/.config/tractor-wifi-control/tls/server.key \
      --operator-key-file /home/al/.config/tractor-wifi-control/stationary-direct.key \
      --diagnostics-status-file /run/tractor-phone-control/stationary-direct-retest-diagnostics.json \
      --log-dir "$TRACTOR_STATIONARY_RETEST_DIR"

There is intentionally no `--no-ntfy` argument. ntfy is diagnostic only and
cannot grant, continue, reset, or extend authority.

Open the printed local `raspberrypi.local:8767` URL. Do not use the ZeroTier
URL for this run. Require all of the following before selecting dry-run Auto:

[ ] Page visibly says DRY RUN — UDP 6004 DISABLED — NO TRACTOR MOTION COMMANDS.
[ ] Terminal says UDP 6004 DISABLED.
[ ] Client IP is in 192.168.8.0/24.
[ ] Authority is tractorfield-mission-custom-subnet.
[ ] Page starts in Pause.
[ ] Physical tractor remains in Pause with rear lever pulled out.

Set a separate ten-minute timer. Then select guarded Auto on this dry-run page
only and immediately record:

    mark "Clean direct Trial B replacement started; ten-minute timer started; dry-run banner confirmed; phone remains on GL-SFT1200-9f4 without walking or switching networks"

Wait the full ten minutes. The Python server does not end itself. Do not walk,
hide the page, lock the screen, change Wi-Fi, or open another control tab.

At ten minutes, return the dry-run page to Pause and record:

    mark "Clean direct Trial B replacement ten-minute interval complete; dry-run page returned to Pause"

Check the diagnostics before stopping the server:

    python3 -m json.tool /run/tractor-phone-control/stationary-direct-retest-diagnostics.json

Record whether ntfy shows `acknowledged`, `queued_for_retry`, or another exact
state. A delayed phone notification is not proof that the server failed to
acknowledge it.

Then press Ctrl+C once in the server terminal. Require a clean stop message.

Create a relative-path checksum manifest that does not hash itself:

    ( cd "$TRACTOR_STATIONARY_RETEST_DIR" && \
      find . -type f ! -name 'SHA256SUMS*' -print0 | sort -z | \
      xargs -0 sha256sum > SHA256SUMS )
    ( cd "$TRACTOR_STATIONARY_RETEST_DIR" && sha256sum -c SHA256SUMS )

Require every listed file to print OK.
